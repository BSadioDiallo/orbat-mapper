# The Vue app stays at the root as the reference until parity is proven

During the migration the Vue app is not moved to `legacy-vue/`: it stays where it is, keeps its build and its 2 637 tests, and serves as the reference the Angular app is compared with (end-to-end checks, serialization fixtures generated by `apps/web/parity/`). The Angular app lives in `apps/web` as a pnpm workspace package. Moving 1 250 files would have broken the reference during the work and made upstream merges impractical; the move of the shared code into `packages/core` and the removal of the Vue app are the last step, and only once the parity matrix (`docs/migration/03-parity-matrix.md`) is verified.
